# Анализ воронки конверсий образовательной платформы

Анализ воронки «визит → регистрация» образовательной платформы за январь–сентябрь 2023. Сравнение конверсии по платформам (web, iOS, Android), выявление аномалий, оценка влияния рекламных кампаний на трафик и регистрации.

## Задача

Исследовать динамику визитов и регистраций, найти причины просадок конверсии, сравнить эффективность платформ и оценить влияние рекламного бюджета на результаты.

## Что сделано

- Загрузка данных из API, очистка (фильтрация ботов, дедупликация визитов)
- Анализ динамики визитов (~1 000/день) и регистраций по дням и платформам
- Расчёт конверсии по платформам: Android (75–85%), iOS (75–85%), Web (2–6%)
- Визуализация периодов рекламных кампаний с цветовыми зонами на графиках
- Анализ влияния рекламных затрат на визиты и регистрации
- Выявление аномального падения конверсии в конце июня — начале июля на всех платформах

## Ключевые выводы

- Web-платформа теряет до 94–98% потенциальных регистраций — основная точка роста
- Android стабильнее iOS по конверсии, рекомендовано перераспределить бюджет
- Синхронное падение на всех платформах в конце июня указывает на технический сбой
- Рекомендовано: аудит воронки регистрации на десктопе, мониторинг резких падений конверсии

## Инструменты

- **Python**: pandas, NumPy, matplotlib, seaborn, Plotly, requests
- **API**: загрузка данных о визитах и регистрациях
- **Superset**: дашборд конверсий
